# Nguồn model 3D

| File | Nguồn | Giấy phép |
|---|---|---|
| `den-duong.glb` | "Lantern" – Khronos glTF Sample Assets (© 2017 Microsoft), https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/Lantern | CC0 1.0 (tự do dùng, không bắt buộc ghi công) |

`den-duong.glb` đã được thu nhỏ texture từ 2048px xuống 512px JPEG (9,5 MB → 0,4 MB) để tải nhanh trên điện thoại.

Thêm model mới: dùng file `.glb`, giữ dưới ~1–2 MB, texture tối đa 1024px, và ghi nguồn + giấy phép vào bảng này.
